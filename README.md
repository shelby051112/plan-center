# 📅 Plan Center — Jikun 的学习与生活计划中心

一个离线可用的单文件计划网站（纯 HTML + JS，无后端、无依赖），通过 GitHub Pages 在手机和电脑上都能使用。

**🔗 在线访问**：<https://shelby051112.github.io/plan-center/>

> 建议手机浏览器打开后「添加到主屏幕」，获得 App 式体验。

---

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 📋 周末 + 下周计划 | 每日时间轴（课表、通勤、视频、读书、法语、健身），每条可打 ✓ / ✗ |
| ✏️ 计划可编辑 | 改时间 / 内容 / 分类，增删条目，一键恢复默认 |
| ✍️ 每周任务 | 自己填写的大事（作业 DDL、约人、报名…），可勾选完成 |
| 🍽️ 饮食计划 | 70kg 减脂饮食（~1600-1700 kcal/日），米饭预约提示 |
| 🛒 食材与采购 | 每日做饭材料清单 + 一周采购清单（**预算 ≤ CAD $100，实际约 $92**） |
| 📊 周报告 & 反馈 | 自动分析完成率、生成优化建议，一键复制反馈文本发给 WorkBuddy |
| ⏰ 提醒 | 浏览器通知 + **.ics 导出到手机系统日历**（含每周任务的定时提醒） |
| 💾 数据管理 | localStorage 本地保存，支持导出 / 导入 JSON 备份跨设备迁移 |

## 🔄 每周更新流程

1. 每周日 20:30（多伦多时间）WorkBuddy 自动提醒周反馈
2. 在网站「周报告 & 反馈」页完成勾选 → 生成反馈文本 → 复制
3. 反馈粘贴给 WorkBuddy，生成新一周计划并重新推送到本仓库
4. 手机刷新网页即是新版（跨设备数据用「导出/导入备份」迁移）

## 🛠️ 技术说明

- 单文件 `index.html`，零依赖零构建，任何静态托管可用
- 数据保存在浏览器 localStorage（每台设备独立）
- 提醒：页面内 Notification API + .ics 日历文件双方案
