# 📅 Plan Center — Jikun 的 UofT 整学期计划中心

一个离线可用的单文件计划网站（纯 HTML + JS，无后端、无依赖），覆盖 **UofT 2026 Fall 全学期 18 周**，通过 GitHub Pages 在手机和电脑上都能使用。

**🔗 在线访问**：<https://shelby051112.github.io/plan-center/>

> 建议手机浏览器打开后「添加到主屏幕」，获得 App 式体验。

---

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 🗓️ 整学期 18 周 | 顶部周选择器任意切换；打开时自动定位到当前周并平滑滚动到今天的卡片 |
| 📚 UofT 课表 | MIE375 / ESC384 / STA347 / STA302 / CHE374 / ESC301，含 LEC/TUT 教室与精确时间 |
| 🎯 考试日期可改 | CHE374 10/14、STA302 10/14、MIE375 10/19、STA347 10/20、ESC384 11/9 已预填，**点日期框随时改期**，当天计划/倒计时/.ics 全部同步 |
| 🏖️ 校历假期 | 感恩节 10/12、阅读周 10/26-10/30、期末考试周 12/10-12/22、寒假 12/24 起自动识别并切换休息模板 |
| ✍️ 每周任务 | 每周一键刷新：归档上周数据 → 自动对应新日期 → 单双周/假期自动判断 |
| 🍽️ 饮食计划 | 4 套菜单每周轮换，**每晚晚餐都有小米粥**，预算全部 ≤ CAD $100（$91.5 ~ $97.5） |
| 🛒 采购清单 | 每周不同清单随菜单轮换，勾选进度自动保存 |
| 📊 周报告 & 反馈 | 自动分析完成率、生成优化建议，一键复制反馈文本发给 WorkBuddy |
| ⏰ 提醒 | 浏览器通知 + **.ics 导出到手机系统日历**（考试、健身、长跑、周复盘、自定义任务提醒） |
| 🏃 日落长跑 | 内置多伦多日落时间计算，周末长跑自动排在日落前出发 |
| 💾 数据管理 | localStorage 本地保存，支持导出 / 导入 JSON 备份跨设备迁移 |

## 🔄 每周更新流程

1. 每周日 20:30（多伦多时间）WorkBuddy 自动提醒周反馈
2. 在网站「周报告 & 反馈」页完成勾选 → 生成反馈文本 → 复制
3. 反馈粘贴给 WorkBuddy；或直接点「🔄 刷新·开始新的一周」自行切换
4. 手机刷新网页即是新版（跨设备数据用「导出/导入备份」迁移）

## 🛠️ 技术说明

- 单文件 `index.html`，零依赖零构建，任何静态托管可用
- 数据保存在浏览器 localStorage（存储键 `jk_uoft_plan_v1`，每台设备独立）
- 提醒：页面内 Notification API + .ics 日历文件双方案
